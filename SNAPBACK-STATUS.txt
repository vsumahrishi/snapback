GIVING TO A STUDENT
-------------------
1. Send the APK (app-debug.apk) OR the website URL.
2. Student installs / opens.
3. Settings -> profile: THEIR name.
4. Settings -> Live sync: THEIR private sync code + YOUR Firebase config
   (same Firebase project is OK; each student MUST use a different sync code).
5. They do NOT open Firebase console day to day.
6. "Reset all data" clears local data only; cloud data for a code remains until overwritten.

Sync code is like a password for that student's data. Do not share codes between students.
