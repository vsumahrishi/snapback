SnapBack — Website / PWA package (build 186)

HOW TO USE
1. Unzip (or use this folder as-is).
2. Host the whole folder on any static host (Netlify, GitHub Pages, school server, etc.)
   OR open index.html in a browser for local testing.
3. Hard-refresh once (Ctrl+Shift+R) so the service worker picks up build 186.
